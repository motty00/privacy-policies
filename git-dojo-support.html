サポート

アプリ名: Git道場 − 図で学ぶGit入門

本ページはiOSアプリ「Git道場」のサポートページです。

よくある質問

Q. 購入した「広告非表示」「レベル5 実務シナリオ編」を復元したい

アプリの設定画面（ホーム右上の歯車）→「購入を復元」をタップしてください。購入時と同じApple Accountでサインインしている必要があります。機種変更後も同じ手順で復元できます。

Q. オフラインで使えますか?

はい。すべてのレッスンとシミュレータは端末内で完結しており、通信なしで動作します。

Q. 本物のGit環境は必要ですか?

不要です。アプリ内のシミュレータがGitの挙動（エラーメッセージ含む）を再現します。GitHubアカウントも必要ありません。

Q. git checkout が使えません

本アプリは現代のGitの推奨に合わせて、ブランチの移動は git switch、ファイルの復元は git restore で教えています。checkout はこの2つの役割を兼ねていた古いコマンドで、レッスン内の深掘りカードで補足しています。

Q. 腕試しモードとは何ですか?

「レベル5 実務シナリオ編」に含まれる反復演習モードです。rebase・cherry-pick・revert・amend のお題がランダムに出題され、解くたびに通算クリア数が増えていきます。

Q. 学習の進捗を消したい／やり直したい

各レッスン内のメニュー（右上の「…」）から「最初からやり直す」で個別にやり直せます。ゴールのない自由実験場として「サンドボックス」もご利用いただけます。
